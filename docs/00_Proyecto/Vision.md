# Visión del producto

Construir una plataforma modular para tiendas que integre comercio electrónico, venta física, dropshipping, proveedores externos, gestoras, influencers, dependientas, mensajeros, inventario, pedidos, reparto de ganancias, seguimiento e IA.

Casa Viva será el primer cliente y entorno de validación, no el nombre interno obligatorio del producto.

## Principios

- Una sola fuente de verdad.
- Sin operaciones importantes fuera del sistema.
- Atribución permanente por primer referente.
- Cliente orgánico sin participación para gestora.
- Sin vencimiento automático de reservas.
- Auditoría obligatoria.
- Permisos por rol.
- Móvil primero.
- Configuración por tienda.
- Arquitectura reutilizable.

## Decisiones cerradas

- WordPress + WooCommerce + tema propio + plugin propio.
- Una ubicación física inicial para Casa Viva.
- Productos propios, externos, por encargo y “Próximamente”.
- Gestora confirma pedidos.
- Dependienta puede vender presencialmente.
- Gestora puede actuar como mensajera.
- Mensajeros propios y externos.
- Mensajería cobrada por el mensajero.
- Reparto Casa Viva: 33,33 % gestora, 33,33 % dependienta y 33,33 % Casa Viva sobre ganancia neta.
- Primera versión incluye los roles principales.
