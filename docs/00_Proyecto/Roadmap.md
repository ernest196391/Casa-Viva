## Criterio de finalización por fase
- Código revisado.
- Pruebas ejecutadas.
- Permisos validados.
- Auditoría validada.
- Responsive probado.
- Rollback disponible.
- Staging aprobado.
- Documentación actualizada.
- Sin secretos.

No empezar una fase grande sin aprobar la anterior.
