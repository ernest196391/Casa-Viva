# Fase 2D — alcance

Esta fase es aditiva sobre el portal de mensajeros existente.

Incluye:
- priorización visual de la entrega activa;
- acción logística principal dominante;
- accesos rápidos a WhatsApp, llamada y navegación en etapas activas compatibles;
- validación Playwright en WordPress/WooCommerce reales;
- conservación de ofertas, QR, incidencias, polling, ubicación en vivo, ganancias y contabilidad existentes.

No incluye:
- nuevas transiciones;
- cambios de tarifas o ganancias;
- rediseño completo;
- navegación propia;
- cambios de payouts o settlements.
