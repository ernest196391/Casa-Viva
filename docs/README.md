# Casa Viva Developer Kit

Este directorio es la fuente de contexto para agentes de programación.

## Orden de lectura

1. `00_Proyecto/Vision.md`
2. `01_Arquitectura/ArquitecturaGeneral.md`
3. El documento del módulo solicitado.
4. `99_Codex/ComoTrabajar.md`

## Documentos por módulo

- Proyecto: visión, alcance y decisiones cerradas.
- Arquitectura: WordPress, WooCommerce, tema, plugin, datos y seguridad.
- Operaciones: centro operativo, pedidos, inventario, mensajería, proveedores y pagos.
- Roles: cliente, gestora, dependienta, mensajero y administración.
- IA: asistente del cliente y herramientas transaccionales.
- UI: sistema visual y pantallas.
- Codex: forma de trabajo, prompts y criterios de aceptación.

## Regla de contexto

No cargues toda la documentación en cada tarea. Lee la visión, la arquitectura y solamente el módulo que se va a modificar.
