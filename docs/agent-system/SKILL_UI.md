# Skill — Casa Viva UI / Design System

## Job

Convert UX decisions into consistent components and measurable visual constraints. The coding agent must not invent a new visual language per screen.

## Design direction

Casa Viva uses a minimal, warm, calm visual language with dark green and beige, aligned with the existing brand direction. Approved brand assets must be used as-is; do not redraw logos inside implementation tasks.

## Component rules

Prefer shared components/tokens for:

- primary/secondary buttons;
- cards and sections;
- inputs/selects/textareas;
- chips/status indicators;
- bottom navigation;
- floating actions;
- bottom sheets/dialogs;
- empty/error/loading states.

## Mobile constraints

- baseline viewport: 360 px;
- primary controls: target height 48–52 px;
- tap targets: at least 44 px;
- no horizontal scroll;
- respect safe-area insets;
- fixed/floating controls must not cover CTAs, form inputs, WhatsApp or bottom navigation;
- no broken words caused by narrow cards;
- visible focus state for keyboard users.

## Visual acceptance

Do not use “premium”, “modern” or “clean” as acceptance criteria. Translate them into hierarchy, spacing, typography, component count, contrast, alignment, responsive behavior and removal of visual noise.

## Output

Produce the `UI CONTRACT`, visual acceptance criteria and required screenshots in `WORK_TASK_CONTRACT.md`.
