# Casa Viva Network — Monetization Matrix V1

## Estado
Paso 4 — COMPLETADO V1.

## Principio rector
Casa Viva monetiza **capacidad, inteligencia, automatización y tiempo recuperado**, no dependencia artificial.

La progresión común será:

1. **FREE — Hazlo**: herramientas esenciales completas.
2. **PRO — Hazlo mejor**: inteligencia, analítica, optimización.
3. **AGENT — Hazlo conmigo**: copilotos y acciones asistidas.
4. **BUSINESS/PREMIUM — Hazlo por mí**: automatizaciones, equipos y delegación supervisada.
5. **APORTE VOLUNTARIO**: comunidad, nunca prioridad operativa o reputación.

## Reglas de monetización

- Free debe resolver un problema real de punta a punta.
- Pagar no compra reputación.
- Pagar no debe comprar injustamente los mejores pedidos básicos.
- La automatización económica requiere permisos y auditoría.
- Un plan superior debe producir ROI medible o ahorro de tiempo.
- Las comisiones transaccionales deben estar separadas de suscripciones, payouts y aportes.

## 6. Aporte voluntario

Puede existir para cualquier actor con reglas estrictas:

- nunca obligatorio;
- nunca penaliza al que no aporta;
- no compra pedidos;
- no compra mejores reseñas;
- no compra posición orgánica encubierta;
- debe explicar qué ayuda a financiar.

## 7. Qué monetizar primero

Prioridad recomendada:

1. B2B / Business OS donde haya ROI directo.
2. Pro de productividad para gestoras y mensajeros.
3. Servicios/marketplace transaccionales donde Casa Viva aporte adquisición, confianza o logística.
4. Cliente Pro solo cuando exista ahorro/valor recurrente demostrable.
5. Agent tiers después de disponer de datos, permisos y automatizaciones maduras.

## 8. Regla para experimentos de precio

Antes de fijar precio:
- medir valor generado;
- medir tiempo ahorrado;
- medir retención;
- comparar con ingreso del actor;
- evitar que el precio destruya el lado de la red que genera liquidez.

Toda tarifa debe ser configurable y auditable; no codificar porcentajes o importes estratégicos de forma rígida en la lógica de dominio.
