# Casa Viva Network — Journey Maps V1

## Estado
Paso 3 — COMPLETADO V1.

## Regla común
Cada actor recorre la misma progresión de valor:

`DESCUBRIR → ACTIVAR → OBTENER VALOR → REPETIR → CRECER → PRO → AGENTE → EMPRESA/DELEGACIÓN`

La versión Free debe ser útil aun cuando la red todavía tenga poca oferta. El efecto red multiplica el valor, no lo crea desde cero.

---

## 1. Mensajero

### Descubrir
Promesa: **consigue trabajo, organiza tu agenda y convierte tu mensajería en un negocio.**

### Activar
Registro corto → vehículo → zonas → disponibilidad → meta económica.

### Primer valor
Puede crear agenda y registrar clientes propios aunque ningún pedido venga todavía de Casa Viva.

### Momento de magia
La app muestra cuánto trabajo tiene mañana, ingreso previsto, huecos libres y oportunidades compatibles.

### Hábito
Abre Casa Viva para responder: **¿cómo está mi negocio hoy?**

### Crecimiento
Agenda → clientes recurrentes → mejores rutas → mejores tarifas → reputación → segundo vehículo.

### Pro
Optimización, CUP/hora, CUP/km, matching, retorno, CRM inteligente, predicción de huecos y Courier Copilot.

### Agent
Reglas autorizadas para alertar, reservar o priorizar oportunidades compatibles.

### Expansión
Flota, otros mensajeros, dispatcher, mantenimiento, rendimiento y empresa logística.

### Resultado
> Entré buscando carreras. Terminé construyendo una operación.

## 2. Gestora

### Descubrir
Promesa: **empieza sin capital y convierte tus relaciones en un negocio.**

### Activar
Nombre/identidad → tienda → productos iniciales → clientes → enlaces.

### Primer valor
Puede crear tienda multinegocio, importar/crear productos, usar CRM y producir contenido aun con pocos comercios conectados.

### Momento de magia
Un producto se convierte con pocos pasos en foto mejorada, descripción, precio, link atribuido y contenido listo para compartir.

### Hábito
Abre Casa Viva para ver: clientes pendientes, oportunidades, pedidos, comisiones y contenido del día.

### Crecimiento
Tienda → cartera → recompra → marca → mejores márgenes → equipo.

### Pro
Scout, CRM inteligente, recomendaciones, analítica, contenido avanzado, mensajero recomendado, metas y automatizaciones sugeridas.

### Agent
Seguimientos, alertas, preparación de campañas, asignación logística y acciones comerciales dentro de reglas autorizadas.

### Expansión
Equipo de gestoras, catálogo propio, marca, supervisión, reparto de oportunidades y microempresa comercial.

### Resultado
> Entré reenviando productos. Terminé administrando una máquina comercial.

## 3. Cliente

### Descubrir
Promesa: **resuelve necesidades de tu casa con menos tiempo, menos incertidumbre y mejor coste total.**

### Activar
Cuenta → ubicación → hogar → preferencias → primeras necesidades.

### Primer valor
Busca y compara por coste puesto en casa, no solo precio del producto.

### Momento de magia
Casa Viva propone la combinación más conveniente entre producto, distancia, mensajería, rapidez y reputación.

### Hábito
Recompra, favoritos, direcciones, historial, seguimiento, profesionales habituales y recordatorios.

### Crecimiento
Compras → memoria del hogar → planificación → optimización → recurrencia.

### Pro
Despensa inteligente, presupuesto, alertas, optimización multi-negocio, planificación de compras y bienestar general.

### Agent
Prepara cestas, recuerda mantenimientos, propone servicios y ejecuta acciones dentro de límites previamente autorizados.

### Expansión
Hogar multiusuario, planes recurrentes y asistencia doméstica integral.

### Resultado
> Entré buscando un producto. Terminé teniendo un sistema que me ayuda a mantener mi casa.

## 4. Negocio

### Descubrir
Promesa: **trae tu negocio; Casa Viva te ayuda a convertirlo en un sistema.**

### Activar
Nombre → WhatsApp → ubicación → catálogo inicial → horario.

### Primer valor
Foto de producto → borrador estructurado → publicación → pedido.

### Momento de magia
Un producto publicado queda disponible para clientes, gestoras y logística sin montar tres sistemas separados.

### Hábito
Panel diario: ventas, stock, pedidos, clientes, gestoras, mensajeros y alertas.

### Crecimiento
Más clientes → recurrencia → mejor inventario → fuerza comercial → logística confiable → equipo.

### Pro
Analítica, reposición, CRM inteligente, recomendaciones de catálogo/precio, branding, contenido y automatizaciones sugeridas.

### Agent
Prepara reposición, campañas, seguimientos, logística y prioridades operativas según reglas.

### Expansión
Sucursales, equipo, permisos, integraciones, API y Business OS.

### Resultado
> Entré administrando todo manualmente. Terminé dirigiendo un sistema.

---

## 5. Profesional

### Descubrir
Promesa: **tú sabes hacer el trabajo; Casa Viva te ayuda a convertirlo en un negocio.**

### Activar
Perfil → especialidad → zona → disponibilidad → portafolio → verificación.

### Primer valor
Puede presentar un perfil profesional, recibir solicitudes y preparar presupuestos.

### Momento de magia
Una necesidad del cliente se convierte en solicitud estructurada con ubicación, fotos, urgencia y contexto suficiente para cotizar.

### Hábito
Agenda, clientes, trabajos, materiales, reputación y cobros.

### Crecimiento
Trabajos → reputación → clientes recurrentes → agenda → especialización → equipo.

### Pro
Presupuestos asistidos, planificación, CRM, recordatorios, materiales, analítica y Professional Copilot.

### Agent
Seguimientos, preparación de cotizaciones, agenda y recordatorios dentro de reglas autorizadas.

### Expansión
Equipo profesional, técnicos, zonas, contratos recurrentes y empresa de servicios.

### Resultado
> Entré buscando trabajos. Terminé construyendo una empresa de servicios.

## 6. Handoffs que crean el efecto red

1. Negocio publica oferta → gestora la descubre.
2. Gestora genera cliente → Order Core conserva atribución.
3. Cliente compra → Logistics busca capacidad.
4. Mensajero entrega → Reputation y Ledger actualizan.
5. Cliente necesita instalación → Services conecta profesional.
6. Profesional necesita materiales → Commerce puede abastecer.
7. Todos los eventos alimentan mejores recomendaciones futuras sin crear fuentes de verdad duplicadas.

## 7. Journey atómico para priorización

`NEGOCIO OFRECE → GESTORA VENDE → CLIENTE COMPRA → MENSAJERO ENTREGA → DINERO/REPUTACIÓN/HISTORIAL SE CIERRAN`

Este ciclo es la primera unidad completa de Casa Viva Network y debe seguir siendo verificable end-to-end durante la evolución.
