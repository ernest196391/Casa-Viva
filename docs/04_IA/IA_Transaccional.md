# IA transaccional

La IA ayuda al cliente a navegar y ejecutar acciones autorizadas sobre datos reales.

## Capacidades iniciales
- Buscar y filtrar productos.
- Comparar.
- Añadir o quitar del carrito.
- Calcular mensajería.
- Localizar y rastrear pedidos.
- Mostrar pedido, producto e identificadores.
- Cambiar datos permitidos.
- Solicitar o ejecutar cancelación según estado.
- Abrir incidencia.
- Transferir a gestora.

## Seguridad
- Herramientas cerradas mediante function calling.
- Verificación de identidad.
- Validación de rol y estado.
- Confirmación explícita antes de acciones irreversibles.
- Registro de parámetros, resultado y usuario.
- Sin acceso SQL libre.
- Nunca inventar estados, precios o políticas.
