# Cómo trabajar con Codex

## Regla principal
Una tarea = un módulo o cambio pequeño.

## Prompt inicial recomendado

Lee `AGENTS.md`, `docs/README.md`, `docs/00_Proyecto/Vision.md`, `docs/01_Arquitectura/ArquitecturaGeneral.md` y el documento del módulo indicado.

No programes todavía. Primero:
1. Audita el código relacionado.
2. Resume cómo funciona actualmente.
3. Enumera contradicciones y riesgos.
4. Propón un plan de cambios con archivos concretos.
5. Espera aprobación.

## Al programar
- Crear rama específica.
- No mezclar módulos.
- Añadir pruebas.
- Ejecutar pruebas disponibles.
- Documentar cambios y rollback.
- Abrir PR borrador.
- No fusionar ni desplegar sin aprobación.

## Para ahorrar créditos
- No adjuntar el documento maestro completo en cada tarea.
- Cargar visión, arquitectura y un solo módulo.
- Pedir respuestas breves y trabajo limitado.
- Evitar sesiones abiertas con objetivos ambiguos.
- Cerrar una tarea antes de empezar otra.
